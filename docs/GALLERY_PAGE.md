# Gallery Page

Halaman `gallery.html` berisi hero, breadcrumb, pengantar, filter, result count, grid, empty state, dialog lightbox, CTA, dan footer. Total 12 gambar terdiri dari sembilan credential lokal dan tiga screenshot aman School Administration Knowledge Assistant. Kategori Projects dan Learning Activities kini menampilkan pengujian daftar ulang, pengujian guardrail, dan Prompt Template. Screenshot Main Flow tidak dipublikasikan karena memperlihatkan area credential yang dimasking.

`assets/js/gallery.js` mengatur filter, reset, result count, dialog, backdrop, focus return, dan scroll lock. Dialog memiliki nama yang dapat diakses, dapat ditutup dengan tombol, Escape bawaan elemen `dialog`, atau backdrop. Tanpa JavaScript semua figure dan caption tetap tersedia.

Pengujian: periksa semua filter, count 12, pembukaan/penutupan dialog, Escape, focus return, keyboard, tema, dan viewport 390/768/1440 px.
