# Project Brief

## Ringkasan proyek

**Raden Dimas Digital Portfolio** adalah website portofolio pribadi profesional sekaligus proyek UAS mata kuliah Pemrograman Web I. Website direncanakan sebagai situs statis multi-page berbahasa Indonesia yang dapat dijalankan melalui server lokal sederhana dan dipublikasikan ke Netlify atau GitHub Pages.

## Latar belakang

Proyek ini menjadi media untuk memperkenalkan Raden Dimas Taufik Rahmat sebagai mahasiswa S1 Informatika yang mempelajari web development, mobile development, data dan Artificial Intelligence, serta pengelolaan teknologi dan sistem informasi. Implementasinya harus tetap cukup sederhana untuk dipahami, dipresentasikan, dan dijelaskan oleh mahasiswa.

## Tujuan

### Akademik

- Memenuhi kebutuhan proyek UAS Pemrograman Web I.
- Mempraktikkan semantic HTML5, modern CSS3, dan vanilla JavaScript.
- Menunjukkan pemahaman struktur multi-page, responsive design, aksesibilitas, validasi formulir, media, dan interaksi antarmuka.
- Menghasilkan proyek yang dapat dijelaskan tanpa ketergantungan framework atau build tool.

### Personal branding

- Menampilkan identitas profesional sebagai mahasiswa S1 Informatika.
- Mengomunikasikan minat pada web, mobile, data, AI, dan pengelolaan teknologi.
- Menyediakan ruang untuk karya, kredensial, media, dan kontak setelah datanya diverifikasi.
- Menggunakan tagline awal: **Informatics Student · Web Developer · Data & AI Enthusiast**.

## Teknologi

- Semantic HTML5.
- Modern CSS3 dengan custom properties.
- Vanilla JavaScript dengan API browser standar.
- Hosting statis melalui Netlify atau GitHub Pages.

Tidak menggunakan framework JavaScript/CSS, jQuery, backend, database, build tool, atau dependency yang tidak diperlukan.

## Arah visual

Konsep **Professional Modern IT Student Portfolio**: dark-first, bersih, elegan, nyaman dibaca, dan berorientasi teknologi. Palet menggunakan deep navy, cyan, purple, putih, dan abu-abu netral; gradient dan efek glass dipakai secara halus. Desain menghindari tampilan gaming, neon berlebihan, dekorasi acak, dan kepadatan visual.

## Batasan proyek

- Situs statis multi-page dengan sebelas halaman yang telah ditentukan.
- Bahasa utama Indonesia dan setiap halaman menggunakan `lang="id"`.
- Data, tautan, jumlah, metrik, dan aset personal yang belum terkonfirmasi diberi label `TODO`.
- Tidak membuat foto personal, sertifikat, credential ID, pengalaman, pencapaian, atau kontak palsu.
- Media tidak autoplay; animasi ringan, responsif, dan menghormati reduced motion.
- Formulir kontak hanya mengarah ke `success.html`, tanpa klaim data dikirim atau disimpan.

## Kriteria keberhasilan

- Semua halaman wajib tersedia, saling terhubung, dan dapat dibuka pada server statis.
- Tampilan stabil pada lebar 360, 390, 768, 1024, dan 1440 piksel tanpa overflow horizontal.
- Navigasi, formulir, galeri, lightbox, video hero dekoratif, tema, dan animasi dapat digunakan dengan keyboard.
- Struktur semantik, heading, focus state, label, alt text, transcript, contrast, dan reduced motion memenuhi rencana aksesibilitas.
- Tidak ada broken link, kesalahan console, aset tak sengaja hilang, atau data palsu.
- Kode mudah dibaca dan dijelaskan dalam konteks Pemrograman Web I.
- Situs berhasil diuji setelah deployment pada platform statis yang dipilih.
